# Phase 14: Automated Publishing & MCP Expansion

## 1. Goal
Convert the local pipeline into a true distribution powerhouse by expanding the `ffmpeg_toolkit` and implementing the `upload_to_platform` MCP distribution layer. The tools will apply branding kits dynamically and execute uploads through a hybrid OAuth/Playwright architecture.

**Depends on:** Phase 13

## 2. Scope / Requirements

### 2.1 Expanding FFmpeg Toolkit (MCP Tools)
- Consolidate new tools identified in `future-mcp-tools.md`:
  - `smart_crop_subject`: Implement OpenCV tracking or Gemini Vision analysis to dynamically track a face/subject and output a moving 9:16 vertical crop.
  - `overlay_video`: A dedicated function mapping secondary video streams (B-roll, split-screen) atop primary footage with timestamp awareness.
- Connect these back into the `FastMCP` developer server.

### 2.2 Branding Kits Standardization
- Standardize the `BrandingProfile` created in Phase 9 across AI-generated scenes.
- Ensure Veo 3.1 generation output explicitly undergoes a branding step that stamps logos and styles captions perfectly according to platform ratios (TikTok/Shorts vs YouTube).

### 2.3 `upload_to_platform` Distribution Layer
- Act upon the research detailed in `future-mcp-tools-distribution.md`:
  - **YouTube:** Utilize the `google-api-python-client` with an OAuth2 consent flow. POST the video, upload a custom `.jpg` thumbnail generated by Gemini Vision, attach title/tags, and schedule.
  - **Spotify for Podcasters:** Since no robust video upload API currently exists, implement a `playwright` headless automation script to inject cookie sessions, navigate to the unified dashboard, and programmatically attach the rendered MP4 to the DOM drag-and-drop zone.
  - **Instagram Reels:** Use the `Instagram Graph API` (linked via Facebook). Ensure 9:16 crop sizing with the `smart_crop_subject` tool, set the cover image via API, and inject captions.
  - **TikTok:** Develop an alternative `playwright` bot handling TikTok's content posting flow natively (avoiding enterprise API barriers).
  - **X (Twitter):** Utilize `tweepy` or standard `px-api-v2` scripts. Implement chunked media upload (`INIT`, `APPEND`, `FINALIZE`, `STATUS`) loops ensuring HD video files >15MB process successfully before attaching the `media_id` to a Tweet.

## 3. Tech Stack Requirements
- Google API Python Client
- Twython / Tweepy (X API v2 Chunking)
- Facebook Graph API wrappers
- Playwright (Headless Browser Automation)

## 4. Success Criteria
1. The `smart_crop_subject` tool dynamically crops a 16:9 4K video containing a moving subject into a 9:16 vertical clip, keeping the subject perfectly centered.
2. The `overlay_video` tool successfully places a 15-second AI-generated B-roll clip atop a primary track.
3. Authenticated YouTube OAuth securely triggers an API call that schedules the final generated podcast with custom thumbnails and branded captions.
4. The Playwright scripts upload the podcast to TikTok/Spotify automatically via a mock UI session simulating user DOM interactions securely.
