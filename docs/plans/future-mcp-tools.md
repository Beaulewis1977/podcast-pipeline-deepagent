It's a perfect foundation, but looking down the road toward a fully automated "Podcast Empire," we will absolutely end up building more tools.

Right now, you have everything needed to cleanly cut, sync, caption, duck audio, brand, and encode your video. The 14 tools are sufficient for the heavy lifting of Phase 9.

However, as an architect looking ahead, here are 3 tools we will almost certainly need to add to the MCP server in the future:

smart_crop_subject: Right now we crop statically. Soon, you'll want a tool that tracks faces and dynamically crops 16:9 landscape podcast footage into 9:16 vertical TikToks/YouTube Shorts, panning left and right to keep the speaker centered.
overlay_video (B-Roll or Picture-in-Picture): Right now you have overlay_image (for branding graphics/logos), but you don't actually have a toolkit function for overlaying a second moving video track (like cutting away to B-roll footage or doing a split-screen interview).
upload_to_platform: We package the video beautifully, but eventually, you'll want your agent to securely trigger the API calls that literally log into YouTube/Spotify and hit "Publish."
