**Brand Studio — Visual Assets expander — Add file uploaders for logo and font (~line 2376):**

Find the existing logo path text input in the Brand Studio editor (Visual Assets expander). Add a `st.file_uploader` above the text input:

```python
# Phase 09-12 (GAP-6A): File uploader for logo alongside text input.
# Determine assets directory within the branding profile's directory.
branding_dir = get_config().branding.branding_dir
assets_dir = Path(branding_dir) / "assets"
assets_dir.mkdir(parents=True, exist_ok=True)

logo_upload = st.file_uploader(
    "Upload Logo",
    type=["png", "svg", "jpg", "jpeg"],
    key="brand_studio_logo_upload",
    help="Upload a logo file. The path field below will update automatically.",
)
if logo_upload is not None:
    dest = assets_dir / logo_upload.name
    dest.write_bytes(logo_upload.getvalue())
    # Pre-fill the text input with the saved path
    logo_path_default = str(dest)
else:
    logo_path_default = profile.logo_path or "" if profile else ""

logo_path = st.text_input(
    "Logo Path",
    value=logo_path_default,
    key="brand_studio_logo",
    help="Path to logo image file (PNG/SVG). Leave empty for no logo.",
)
```

Do the same for the font path text input — add a font file uploader above it:

```python
font_upload = st.file_uploader(

    type=["ttf", "otf", "woff", "woff2"],
    key="brand_studio_font_upload",

)

else:

    help="Path to font file (TTF/OTF). Leave empty for default.",
)
```

- `write_bytes()` is idempotent — re-writing same bytes on Streamlit rerun is harmless.
