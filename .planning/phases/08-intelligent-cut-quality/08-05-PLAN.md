Replace the subprocess invocation block in `generate()` with the research-verified pattern:

```python
# Use output_dir as the working directory. RIFE writes to ./output/ relative to cwd.
work_dir = output_dir
work_dir.mkdir(parents=True, exist_ok=True)

cmd = [
    "python",
    str(self.script_path.resolve()),
    "--img",
    str(frame_a.resolve()),
    str(frame_b.resolve()),
    "--exp",
    str(exp),
]
# NOTE: No --output flag. Upstream inference_img.py does not accept it.
# RIFE writes to ./output/ relative to cwd.
# NOTE: No --cpu flag (does not exist). For CPU: set CUDA_VISIBLE_DEVICES="" in env.

logger.info(
    "rife_generating",
    exp=exp,
    num_frames=num_frames,
    frame_a=str(frame_a),
    frame_b=str(frame_b),
    work_dir=str(work_dir),
)

result = subprocess.run(cmd, cwd=str(work_dir), capture_output=True, text=True, check=False)
if result.returncode != 0:
    logger.error(
        "rife_failed",
        returncode=result.returncode,
        stderr=result.stderr[:500],
        stdout=result.stdout[:200],
    )
    return []

# RIFE outputs to ./output/img*.png relative to cwd
generated = sorted((work_dir / "output").glob("img*.png"))
logger.info("rife_generated", count=len(generated), work_dir=str(work_dir))
return generated
```

Key changes:
1. **Remove `"--output", str(output_dir.resolve())`** from cmd list -- flag does not exist in upstream inference_img.py
2. **Set `cwd=str(work_dir)`** where work_dir = output_dir -- RIFE writes output relative to cwd
3. **Change glob pattern** from `output_dir.glob("*.png")` to `(work_dir / "output").glob("img*.png")` -- RIFE creates an `output/` subdirectory and uses `img` prefix
4. **Resolve script_path** in cmd so it works when cwd differs from rife_dir
