# Phase 8 Plan 05: Render — Pose-Match + RIFE Frame Interpolation

## Objective

For each content-join cut point, scan ±200ms to find the frame pair with minimum
optical-flow distance (speaker poses most similar), then generate 4–8 RIFE bridge
frames when the best-pair distance still exceeds the threshold. Splices bridge
frames into the FFmpeg filtergraph using the concat demuxer.

## Hardware

- **GPU:** NVIDIA RTX 5060 Ti 16 GB (CUDA compute 8.9)
- **Expected RIFE latency:** < 50ms per frame pair at 1080p

def pose_distance(frame_a, frame_b) -> float:
    """Mean Farneback optical flow magnitude in central 60% ROI."""
    import cv2
    roi = lambda f: cv2.cvtColor(
        f[int(f.shape[0]*0.2):int(f.shape[0]*0.8),
          int(f.shape[1]*0.2):int(f.shape[1]*0.8)],
        cv2.COLOR_BGR2GRAY
    )
    flow = cv2.calcOpticalFlowFarneback(
        roi(frame_a), roi(frame_b), None,
        0.5, 3, 15, 3, 5, 1.2, 0
    )
    mag, _ = cv2.cartToPolar(flow[..., 0], flow[..., 1])
    return float(mag.mean())

### rife_bridge.py

```python
class RifeBridge:
    def generate_bridge_frames(
        self, frame_a, frame_b, output_dir, *, num_frames=4
    ) -> list[Path]:
        cmd = [
            "python", self.script_path,
            "--img", str(frame_a), str(frame_b),
            "--output", str(output_dir),
            "--n", str(num_frames),
        ] + ([] if self.gpu else ["--cpu"])
        result = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
        if result.returncode != 0:
            raise RuntimeError(f"RIFE failed: {result.stderr[:500]}")
        frames = sorted(output_dir.glob("*.png"))
        if not frames:
            raise RuntimeError("RIFE produced no output frames")
        return frames
```
