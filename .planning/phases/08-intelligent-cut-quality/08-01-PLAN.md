# Phase 8 Plan 01: Foundation — FillerConfig + FillerCut Enrichment

## Objective

Restructure `FillerConfig` from a flat word list into categorised sub-lists
(`disfluencies`, `hedge_words`, `custom_words`) and enrich the `FillerCut`
transcript model with `category`, `pause_before_ms`, `pause_after_ms`,
`context_before`, `context_after`, and `protected` — all with safe defaults so
existing `filler_cuts.json` artifacts load without modification.

## Scope

**Files to modify:**
- `src/podcast_pipeline/config/settings.py` — `FillerConfig` restructure
- `src/podcast_pipeline/models/transcript.py` — `FillerCut` new fields
- `src/podcast_pipeline/stages/transcribe.py` — `_detect_fillers()` upgrade
- `config.yaml` — new filler config section
- `tests/test_transcribe.py` — category, pause-gate, context tests
- `tests/test_models.py` — FillerCut backward compat round-trip

**Files NOT in scope:**
- Review stage, render stage, UI — those are Plan 03+

## Tasks

### Task 1: Restructure FillerConfig

**File:** `src/podcast_pipeline/config/settings.py`

Replace:
```python
class FillerConfig(BaseModel):
    words: list[str] = Field(default_factory=lambda: ["um","uh","hmm",...])
    min_confidence: float = 0.5
    min_duration_ms: int = 150
    padding_ms: int = 50
```

With:
```python
class FillerConfig(BaseModel):
    """Filler word detection and triage configuration."""

    disfluencies: list[str] = Field(
        default_factory=lambda: ["um", "uh", "hmm", "er", "ah"]
    )
    hedge_words: list[str] = Field(
        default_factory=lambda: ["like", "you know", "basically", "actually", "so"]
    )
    custom_words: list[str] = Field(default_factory=list)

    # Backward-compat flat list — merged into disfluencies at detection time
    words: list[str] = Field(default_factory=list)

    min_confidence: float = 0.5
    min_duration_ms: int = 150
    padding_ms: int = 50

    # Pause gate
    protect_pause_threshold_ms: float = Field(default=300.0, ge=0.0)

    # LLM triage (used by Plan 02)
    enable_llm_triage: bool = True
    llm_triage_model: str = "gpt-4o-mini"
    llm_triage_max_context_words: int = 5
```

Update `config.yaml` smoothing section with new filler keys.

### Task 2: Enrich FillerCut model

**File:** `src/podcast_pipeline/models/transcript.py`

Add to `FillerCut`:
```python
category: Literal["disfluency", "hedge", "custom"] = "disfluency"
pause_before_ms: float = 0.0
pause_after_ms: float = 0.0
context_before: str = ""
context_after: str = ""
protected: bool = False
```

All fields default-safe. Existing serialised files without these keys load as
all-disfluency with zero pauses.

### Task 3: Upgrade _detect_fillers()

**File:** `src/podcast_pipeline/stages/transcribe.py`

Key changes to `_detect_fillers()`:

1. Build three normalised lookup sets from `FillerConfig`:
   ```python
   disfluency_set = {normalize(w) for w in config.fillers.disfluencies}
   disfluency_set |= {normalize(w) for w in config.fillers.words}  # compat
   hedge_set       = {normalize(w) for w in config.fillers.hedge_words}
   custom_set      = {normalize(w) for w in config.fillers.custom_words}
   ```

2. For each detected filler at index `i`:
   - Look up `category` from the three sets
   - Compute `pause_before_ms`: `(word.start - words[i-1].end) * 1000` if `i > 0`
   - Compute `pause_after_ms`: `(words[i+1].start - word.end) * 1000` if `i+1 < len`
   - Slice context words (up to N words before/after)
   - Set `protected = pause_before_ms >= threshold or pause_after_ms >= threshold`

3. Pass all new fields into `FillerCut(...)` constructor.

4. For multi-word fillers (phrases like "you know"):
   - Apply the same pause measurement at phrase boundaries (before first word, after last word)
   - Category = "hedge" for all multi-word phrases in hedge_words
