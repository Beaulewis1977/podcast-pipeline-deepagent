**Step A — Enrich FillerCut model** in `src/podcast_pipeline/models/transcript.py`:

Add these fields to `FillerCut` (all optional/defaulted for backward compat):

```python
from typing import Literal

class FillerCut(BaseModel):
    start: float = Field(ge=0.0)
    end: float = Field(ge=0.0)
    word: str
    confidence: float = Field(ge=0.0, le=1.0)

    # Phase 8 additions — all optional/defaulted for backward compat
    category: Literal["disfluency", "hedge", "custom"] = "disfluency"
    pause_before_ms: float = 0.0
    pause_after_ms: float = 0.0
    context_before: str = ""
    context_after: str = ""
    protected: bool = False
```

All new fields have safe defaults. A legacy `filler_cuts.json` without these fields deserializes as `category="disfluency"`, `protected=False`, etc.

**Step B — Upgrade `_detect_fillers()`** in `src/podcast_pipeline/stages/transcribe.py`:

1. Build three sets from config: `disfluency_set` (from `config.fillers.disfluencies` UNION `config.fillers.words`), `hedge_set` (from `config.fillers.hedge_words`), `custom_set` (from `config.fillers.custom_words`). Use `_normalize_filler_token()` for all.
2. Build combined `all_fillers` set (union of all three) for matching — keep existing matching logic for single/multi word.
3. After detecting a filler match at word index `i` in a segment:
   - **Category**: If normalized word is in `hedge_set` -> "hedge", elif in `custom_set` -> "custom", else "disfluency".
   - **Pause before**: If `i > 0`, compute `(word.start - words[i-1].end) * 1000`. Else 0.0.
   - **Pause after**: If `i+1 < len(words)` (or `i+phrase_len < len(words)` for multi-word), compute `(words[next_idx].start - last_word.end) * 1000`. Else 0.0.
   - **Context before**: Join word texts for `words[max(0, i - N):i]` where `N = config.fillers.llm_triage_max_context_words`.
   - **Context after**: Join word texts for `words[i+phrase_len:i+phrase_len+N]`.
   - **Protected**: True if `pause_before_ms >= config.fillers.protect_pause_threshold_ms` or `pause_after_ms >= config.fillers.protect_pause_threshold_ms`.
4. Pass these new fields into `FillerCut(...)` constructor alongside existing `start`, `end`, `word`, `confidence`.

Important: Keep the existing padding logic (`padding_ms`) for `start`/`end` unchanged. Pause measurements use the RAW word timestamps (before padding), not padded values.
