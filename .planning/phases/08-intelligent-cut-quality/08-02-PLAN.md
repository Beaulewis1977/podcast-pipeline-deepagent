# Phase 8 Plan 02: LLM Semantic Filler Triage

## Objective

Add a `_triage_fillers()` sub-stage to `AnalyzeStage` that sends hedge fillers
(those NOT already `protected`) to the LLM in batches and writes the verdict to
`analysis/filler_triage.json`. This allows the review stage to set
`default_action` intelligently based on semantic context.

## Scope

**Files to create:**
- `src/podcast_pipeline/models/triage.py` — `FillerTriage` Pydantic model

**Files to modify:**
- `src/podcast_pipeline/stages/analyze.py` — `_triage_fillers()` method
- `tests/test_triage.py` — model + prompt format + batch + disabled-path tests

**Files NOT in scope:**
- Review stage (Plan 03), render stage (Plan 04+)

## Tasks

### Task 1: Create FillerTriage model

**File:** `src/podcast_pipeline/models/triage.py`

```python
from __future__ import annotations
from pydantic import BaseModel, Field


class FillerTriage(BaseModel):
    """LLM semantic verdict for a single hedge filler detection."""

    filler_index: int = Field(ge=0)
    word: str
    category: str
    context_before: str
    context_after: str
    pause_before_ms: float
    pause_after_ms: float
    safe_to_remove: bool
    reason: str
    llm_model: str
    triaged_at: str   # ISO 8601


class FillerTriageResult(BaseModel):
    """Full triage result for a job."""

    job_id: str
    total_fillers: int
    triaged_count: int     # hedge fillers sent to LLM
    skipped_count: int     # disfluencies not sent + protected fillers
    disabled: bool         # True when enable_llm_triage=False
    items: list[FillerTriage] = Field(default_factory=list)
    created_at: str
```

### Task 2: Add _triage_fillers() to AnalyzeStage

**File:** `src/podcast_pipeline/stages/analyze.py`

Add after the transcript/analysis artifacts are loaded:

```python
def _triage_fillers(
    self,
    filler_cuts: list[FillerCut],
    *,
    job_id: str,
) -> FillerTriageResult:
    """Run LLM semantic triage on hedge fillers not protected by pause gate."""
    from datetime import datetime, timezone

    now = datetime.now(timezone.utc).isoformat()
    config = self.config.fillers

    # Only hedge fillers that are not already protected
    to_triage = [
        (i, f) for i, f in enumerate(filler_cuts)
        if f.category == "hedge" and not f.protected
    ]

    skipped = len(filler_cuts) - len(to_triage)

    if not config.enable_llm_triage or not to_triage:
        return FillerTriageResult(
            job_id=job_id,
            total_fillers=len(filler_cuts),
            triaged_count=0,
            skipped_count=skipped,
            disabled=not config.enable_llm_triage,
            items=[],
            created_at=now,
        )

    # Batch into groups of 20
    BATCH_SIZE = 20
    items: list[FillerTriage] = []
    for batch_start in range(0, len(to_triage), BATCH_SIZE):
        batch = to_triage[batch_start : batch_start + BATCH_SIZE]
        results = self._call_llm_triage_batch(batch, config=config)
        items.extend(results)

    return FillerTriageResult(
        job_id=job_id,
        total_fillers=len(filler_cuts),
        triaged_count=len(to_triage),
        skipped_count=skipped,
        disabled=False,
        items=items,
        created_at=now,
    )
```

### Task 3: LLM prompt format

The batch call sends all N fillers in one prompt to minimise API round-trips:

```
SYSTEM:
You are a professional audio editor deciding which filler words to remove from a
podcast. For each filler below, decide if it can be SAFELY removed without
changing meaning, tone, or rhetorical intent.
Reply with a JSON array, one object per filler, in the same order:
[{"index": 0, "safe": true/false, "reason": "one sentence"}, ...]

USER:
Fillers to evaluate:

0. Word: "like"
   Context: "...and it was [LIKE] really just..."
   Pause before: 20ms  Pause after: 15ms

1. Word: "like"
   Context: "...and I thought — [LIKE] — isn't that wild?"
   Pause before: 340ms  Pause after: 280ms

...
```

Parse response JSON; if parse fails → all items `safe_to_remove=False` with
`reason="llm_parse_error"`. Never crash the analysis stage for a triage failure.
