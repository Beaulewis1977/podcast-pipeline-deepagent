### Task 4: GPU smoke test script

**File:** `scripts/smoke_test_gpu_rife.py`

```python
#!/usr/bin/env python3
"""Manual GPU smoke test for RIFE frame interpolation on RTX hardware.
Run: uv run python scripts/smoke_test_gpu_rife.py
"""
import sys
import tempfile
from pathlib import Path
import numpy as np
import cv2
from podcast_pipeline.utils.rife_bridge import RifeBridge
from podcast_pipeline.config.settings import load_config

def main():
    config = load_config()
    print(f"RIFE script: {config.smoothing.rife_script_path}")
    print(f"GPU enabled: {config.smoothing.rife_gpu}")

    # Generate two synthetic 1280×720 test frames
    with tempfile.TemporaryDirectory() as tmp:
        tmp = Path(tmp)
        frame_a = (np.random.rand(720, 1280, 3) * 255).astype(np.uint8)
        frame_b = (np.random.rand(720, 1280, 3) * 255).astype(np.uint8)
        cv2.imwrite(str(tmp / "frame_a.png"), frame_a)
        cv2.imwrite(str(tmp / "frame_b.png"), frame_b)

        bridge = RifeBridge(
            script_path=config.smoothing.rife_script_path,
            gpu=config.smoothing.rife_gpu,
        )

        if not bridge.is_available():
            print("ERROR: RIFE script not found.", file=sys.stderr)
            sys.exit(1)

        import time
        t0 = time.perf_counter()
        frames = bridge.generate_bridge_frames(
            tmp / "frame_a.png",
            tmp / "frame_b.png",
            tmp / "rife_out",
            num_frames=config.smoothing.rife_num_bridge_frames,
        )
        elapsed_ms = (time.perf_counter() - t0) * 1000

        print(f"RIFE OK: {len(frames)} bridge frames in {elapsed_ms:.0f}ms")
        if elapsed_ms > 5000:
            print("WARNING: RIFE took > 5s — GPU may not be active.")

if __name__ == "__main__":
    main()
```

## Phase 8: Intelligent Cut Quality

### Filler Control

Phase 8 introduces semantic filler triage:

| Category | Examples | Default | Configurable via |
|---|---|---|---|
| Disfluency | um, uh, hmm, er, ah | auto-remove | `fillers.disfluencies` |
| Hedge | like, you know, basically | review (LLM decides) | `fillers.hedge_words` |
| Custom | operator-defined | configurable | `fillers.custom_words` |
| Protected | any filler near 300ms+ pause | always keep | `fillers.protect_pause_threshold_ms` |

LLM triage can be disabled: `fillers.enable_llm_triage: false`

### Invisible Cut Rendering

All enabled by default; disable individually in `config.yaml`:

| Feature | Config key | Requires |
|---|---|---|
| De-breathing | `smoothing.de_breathing_enabled` | silero-vad |
| Noise-floor match | `smoothing.noise_floor_match_enabled` | librosa |
| Pose-match selection | `smoothing.pose_match_enabled` | opencv-python |
| RIFE bridge frames | `smoothing.rife_enabled` | practical-RIFE + GPU |

### GPU Setup (RTX / CUDA)

### Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| RIFE not called despite high pose score | `rife_enabled: false` or script missing | Check path + `is_available()` |
| RIFE takes > 10s | GPU not active — running on CPU | Verify `torch.cuda.is_available()` |
| Hedge fillers still auto-removed | `enable_llm_triage: false` | Enable or set default_action manually in review UI |
| Protected filler removed anyway | User override in UI | 🔒 is advisory; editor can override |
| De-breathing extends silence too much | `de_breathing_max_extend_ms` too high | Reduce to 80–100ms |
```
