# Phase 8 Plan 03: Review + UI Wiring

## Objective

Wire the enriched `FillerCut` fields and `FillerTriage` results from Plans 01/02
into the review stage's `FillerCutRange` construction, so that `default_action`
is set correctly per filler. Update the Streamlit UI to display context snippets,
pause duration badges, and protection status alongside each filler decision.

## Scope

**Files to modify:**
- `src/podcast_pipeline/stages/review.py` — `FillerCutRange` construction + triage loading
- `src/podcast_pipeline/ui/app.py` — filler card: context, pause badges, lock icon, LLM reason
- `tests/test_review.py` — default_action derivation tests
- `tests/test_ui_app.py` — UI enriched filler card rendering tests
- `tests/test_pipeline.py` — enriched FillerCutRange in edit_plan.json integration test

**Files NOT in scope:**
- Render stage (Plans 04/05)

## Tasks

### Task 1: Load triage artifact in review stage

**File:** `src/podcast_pipeline/stages/review.py`

In `write_edit_plan()` (or wherever `filler_cuts.json` is hydrated):

```python
# Load enriched filler cuts
filler_cuts = [FillerCut.model_validate(f) for f in filler_cuts_data]

# Load triage if present (optional — jobs without Plan 02 run are fine)
triage_path = analysis_dir / "filler_triage.json"
triage_map: dict[int, FillerTriage] = {}
if triage_path.exists():
    from podcast_pipeline.models.triage import FillerTriageResult
    result = FillerTriageResult.model_validate_json(triage_path.read_text())
    triage_map = {item.filler_index: item for item in result.items}
```

### Task 2: Derive default_action per filler

```python
for idx, filler_cut in enumerate(filler_cuts):
    triage = triage_map.get(idx)

    if filler_cut.protected:
        default_action = "keep"                    # pause gate protection
    elif filler_cut.category == "disfluency":
        default_action = "remove"                  # um / uh / hmm / er / ah
    elif triage is not None and triage.safe_to_remove:
        default_action = "remove"                  # LLM cleared this hedge
    else:
        default_action = "review"                  # hedge or LLM uncertain / no triage

    filler_range = FillerCutRange(
        ...
        category=filler_cut.category,
        context_before=filler_cut.context_before,
        context_after=filler_cut.context_after,
        editorial_action=default_action,
        protected=filler_cut.protected,
        pause_before_ms=filler_cut.pause_before_ms,
        pause_after_ms=filler_cut.pause_after_ms,
        llm_safe_to_remove=triage.safe_to_remove if triage else None,
        llm_reason=triage.reason if triage else "",
    )
```

Also add `protected`, `pause_before_ms`, `pause_after_ms`, `llm_safe_to_remove`,
`llm_reason` to `FillerCutRange` in `src/podcast_pipeline/models/edit_plan.py`.

### Task 3: UI filler card enrichment

**File:** `src/podcast_pipeline/ui/app.py`

In the per-filler card (inside the category-grouped filler review section):

```
┌─────────────────────────────────────────────────────────────────┐
│  🔒 [like]   ||20ms||  "...and it [like] really was..."  ||15ms||│
│  LLM: "Safe — used as emphasis filler, no semantic load"        │
│  [keep] [remove]                                                │
└─────────────────────────────────────────────────────────────────┘
```

Implementation:
- Context snippet: `f"...{context_before} [{word.upper()}] {context_after}..."`
- Pause badges: `st.badge(f"||{pause_before_ms:.0f}ms||")` before and after context
- Lock icon: if `filler_cut.protected` → prefix `🔒` to widget label; default to "keep"
- LLM reason: `st.caption(llm_reason)` under the toggles when reason is non-empty
- Category group headers: `Disfluencies (auto-remove)` / `Hedges (review)` / `Custom`
