**Step A — Add fields to FillerCutRange** in `src/podcast_pipeline/models/edit_plan.py`:

Add these additive fields (all optional/defaulted for backward compat):

```python
# Phase 8 additions to FillerCutRange
protected: bool = False
pause_before_ms: float = 0.0
pause_after_ms: float = 0.0
llm_safe_to_remove: bool | None = None   # None = not triaged
llm_reason: str = ""
```

All new fields have safe defaults. A legacy edit_plan.json without these fields deserializes cleanly.

**Step B — Wire triage results into review.py:**

In `write_edit_plan` (or the helper that builds FillerCutRange list from filler_cuts.json), add logic to:

1. Load `analysis/filler_triage.json` from job_dir if it exists. Build a dict mapping `filler_index -> FillerTriageResult`.
2. For each filler cut being converted to a FillerCutRange:
   - Copy `protected`, `pause_before_ms`, `pause_after_ms` from the enriched FillerCut (if fields present; else use defaults).
   - Look up triage result by index. If found, set `llm_safe_to_remove = triage.safe_to_remove` and `llm_reason = triage.reason`.
   - **Derive editorial_action** (this is the default_action logic):
     - If filler_cut is `protected` → `editorial_action = "keep"`
     - Elif filler_cut.category == "disfluency" → `editorial_action = "remove"`
     - Elif triage exists AND `triage.safe_to_remove == True` → `editorial_action = "remove"`
     - Else → `editorial_action = "review"` (hedge without LLM clearance or no triage)
   - This default can still be overridden by explicit user decisions (existing filler_decisions logic takes priority).
3. If filler_triage.json doesn't exist, all hedges default to `editorial_action = "review"`.
4. Preserve existing backward compatibility: when filler_decisions are present, they override the derived default.

**Step C — Add tests in tests/test_review.py:**

- `test_editorial_action_protected_filler_defaults_keep`: Protected filler → editorial_action="keep".
- `test_editorial_action_disfluency_defaults_remove`: Disfluency → editorial_action="remove".
- `test_editorial_action_hedge_llm_safe_defaults_remove`: Hedge with triage safe_to_remove=True → "remove".
- `test_editorial_action_hedge_llm_review_defaults_review`: Hedge with triage safe_to_remove=False → "review".
- `test_editorial_action_hedge_no_triage_defaults_review`: Hedge with no triage result → "review".
- `test_editorial_action_explicit_decision_overrides_default`: User filler_decision "keep" overrides computed "remove".
- `test_filler_cut_range_backward_compat_no_phase8_fields`: Deserialize legacy FillerCutRange JSON → new fields default safely.
