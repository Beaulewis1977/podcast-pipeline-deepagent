    3. Modify `start_sidecar` command:
       - BEFORE checking the PID guard, call `backend_is_healthy().await`

       - After successful spawn, set `TAURI_OWNS_SIDECAR.store(true, Ordering::SeqCst)`

       - If `true`, proceed with existing kill logic
       - After successful kill, set `TAURI_OWNS_SIDECAR.store(false, Ordering::SeqCst)`

    5. The `sidecar_status` command does NOT change — it reports stored PID state regardless of ownership.
