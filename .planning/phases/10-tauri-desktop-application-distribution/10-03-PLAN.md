  <action>
    Create directories `desktop/src/stores/` and `desktop/src/hooks/`.

    1. **`desktop/src/stores/uiStore.ts`** — Zustand v5 store:
       - Import `create` from `zustand`
       - Interface `UIStore`:
         - `selectedJobId: string | null`
         - `activeView: 'ingestion' | 'audio' | 'transcript' | 'branding'`
         - `sidebarCollapsed: boolean`
         - `setSelectedJob: (id: string | null) => void`
         - `setActiveView: (view: UIStore['activeView']) => void`
         - `toggleSidebar: () => void`
       - Export `useUIStore = create<UIStore>((set) => ({ ... }))`
       - Default: `selectedJobId: null`, `activeView: 'ingestion'`, `sidebarCollapsed: false`

    2. **`desktop/src/stores/sidecarStore.ts`** — Zustand v5 store:
       - Import `create` from `zustand`
       - Import `BackendStatus`, `SidecarStatus` from `../lib/backend`
       - Interface `SidecarStore`:
         - `status: BackendStatus` (default: `'disconnected'`)
         - `sidecar: SidecarStatus | null` (default: `null`)
         - `error: string | null` (default: `null`)
         - `setStatus: (status: BackendStatus) => void`
         - `setSidecar: (sidecar: SidecarStatus | null) => void`
         - `setError: (error: string | null) => void`
         - `setConnected: () => void` — sets status='connected', clears error
         - `setDisconnected: (error?: string) => void` — sets status='disconnected', optionally sets error
       - Export `useSidecarStore = create<SidecarStore>((set) => ({ ... }))`

    3. **`desktop/src/hooks/useJobs.ts`** — TanStack Query hook:
       - Import `useQuery` from `@tanstack/react-query`
       - Import `listJobs`, `type JobSummary` from `../lib/backend`
       - Export `function useJobs()`:
         - Return `useQuery({ queryKey: ['jobs'], queryFn: listJobs, refetchInterval: 5000 })`
       - Type the return as `UseQueryResult` containing `JobSummary[]`

    4. **`desktop/src/hooks/useJobDetail.ts`** — TanStack Query hook:
       - Import `useQuery` from `@tanstack/react-query`
       - Import `getJob`, `type JobDetail` from `../lib/backend`
       - Export `function useJobDetail(jobId: string | null)`:
         - Return `useQuery({ queryKey: ['jobs', jobId], queryFn: () => getJob(jobId!), enabled: jobId !== null, refetchInterval: 5000 })`
       - When `jobId` is null, the query is disabled (TanStack Query won't fire)

    5. **`desktop/src/hooks/useSidecarReady.ts`** — TanStack Query hook:
       - Import `useQuery` from `@tanstack/react-query`
       - Import `checkHealth`, `type HealthResponse` from `../lib/backend`
       - Export `function useSidecarReady()`:
         - Return `useQuery({ queryKey: ['health'], queryFn: checkHealth, refetchInterval: 5000 })`
       - The returned `data` is `HealthResponse | null`

    6. **`desktop/src/hooks/useSystemStatus.ts`** — TanStack Query hook:
       - Import `useQuery` from `@tanstack/react-query`
       - Import `BACKEND_PORT` from `../lib/backend`
       - Define interface `SystemStatus { ready: boolean; binaries: Record<string, { status: string; path: string | null; source: string }>; model: { name: string; status: string; path: string | null }; issues: string[] }`
       - Implement `fetchSystemStatus`: `fetch(\`http://127.0.0.1:${BACKEND_PORT}/system/status\`).then(r => r.json())`
       - Export `function useSystemStatus()`:
         - Return `useQuery({ queryKey: ['system-status'], queryFn: fetchSystemStatus, refetchInterval: 10000 })`
       - Refetch every 10s (less frequent — system status changes slowly)

    All files must use strict TypeScript (no `any`), match the project's existing code style (see `backend.ts`), and export named functions (not default exports).
