    - wavesurfer.js: Use `WaveSurfer` from `wavesurfer.js` directly (NOT `@wavesurfer/react` — the React hook has lifecycle issues with multi-instance). Create wavesurfer instances manually with `WaveSurfer.create()` and manage refs.

    **CRITICAL wavesurfer.js v7 notes:**
    - Plugin arrays MUST be memoized — do NOT create new plugin arrays on each render
    - Use `useRef` for the WaveSurfer instance, NOT state
    - Call `.destroy()` on cleanup
    - Create the instance inside a `useEffect` with the container ref, not during render

    **Structure:**

    a) **Job selector header** (top):
       - Show selected job ID from `useUIStore().selectedJobId`
       - If no job selected: "Select a job from Ingestion view"
       - If job selected but ingest stage not complete: "Audio available after ingest stage"

    b) **Waveform Display Area** (main content):
       - Container div with `ref` for wavesurfer mounting
       - Initialize WaveSurfer.create() in useEffect when job has audio:
         ```typescript
         useEffect(() => {
           if (!containerRef.current || !audioUrl) return;

           const ws = WaveSurfer.create({
             container: containerRef.current,
             waveColor: 'var(--color-text-secondary)',
             progressColor: 'var(--color-accent)',
             cursorColor: 'var(--color-accent-hover)',
             barWidth: 2,
             barGap: 1,
             barRadius: 2,
             height: 128,
             normalize: true,
             backend: 'WebAudio',
           });

           ws.load(audioUrl);
           wsRef.current = ws;

           return () => {
             ws.destroy();
             wsRef.current = null;
           };
         }, [audioUrl]);
         ```
       - For audio URL: The backend may not serve raw audio files directly. Use a pragmatic approach:
         1. If the ingest stage output includes audio file paths, try loading from local file (Tauri can access local files)
         2. If not available, show a placeholder waveform area with "Audio waveform preview" and sync controls only
       - Style the container: `bg-[var(--color-bg-card)] rounded-lg p-4 border border-[var(--color-border)]`

    c) **Sync Controls** (below waveform):
       - **Auto-detected offset display**: Read sync offset from job stage outputs if available. Display: "Auto-detected offset: +42ms (confidence: 0.87)"
       - **Manual offset slider**: Range input from -5000ms to +5000ms with 1ms steps
         - Default value: auto-detected offset if available, 0 otherwise
         - Display current value: "Offset: +42ms"
         - Use Tailwind for slider styling: `accent-[var(--color-accent)]`
       - **Apply button**: Posts sync offset back to backend (deferred — for now just displays value)
       - **Reset button**: Resets slider to auto-detected value

    d) **Track Info Panel** (right side or below):
       - Number of audio tracks detected
       - Sample rate, duration, format info (from job detail)
       - Track labels (if multi-track: "Track 1: Camera Mic", "Track 2: Lapel Mic" etc.)

    **Playback controls** (toolbar):
    - Play/Pause button (toggles wavesurfer.playPause())
    - Current position / total duration display (mm:ss)
    - Zoom slider (adjusts wavesurfer.zoom())

    **Fallback states:**
    - No job selected: centered message
    - Job selected but no audio yet: progress indicator from job stage status
    - Audio available but wavesurfer fails to load: error message with raw file path display

    Export named: `export function AudioSyncView()`
